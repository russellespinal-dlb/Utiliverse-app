How to edit, convert, and compress PDFs online for free

Most online PDF tools work by uploading your file to a server, processing it there, and sending a result back — which means your document, however sensitive, passes through someone else's infrastructure. PDF Toolkit Pro takes a different approach: every tool on this page runs as JavaScript inside your browser tab. Merging pulls pages directly from the files you selected in memory; image conversion draws your photos onto a new PDF canvas; text extraction reads the PDF's internal text layer; compression re-renders pages at a lower resolution — all without a network request carrying your file anywhere.

To merge PDFs, drop your files into the Merge tool, drag them into the order you want, and click merge — the tool stitches every page from every file into one download. To digitize photos or scans, use Image to PDF: choose portrait or landscape and a margin, and each image becomes one page. To pull text out of a PDF for editing elsewhere, use the extractor, which reads text page-by-page and lets you edit the result before saving it as .txt or .docx. To shrink a large PDF for emailing, use the compressor and pick Low, Medium, or High — higher compression trades more visual detail for a smaller file.

Frequently asked questions

Are my files uploaded to a server when I use PDF Toolkit Pro?+
No. Every tool on this page runs entirely inside your web browser using JavaScript libraries loaded once from a CDN. Your PDFs and images are read, processed, and converted on your own device and are never transmitted anywhere.
Is there a file size limit for merging or compressing PDFs?+
There's no artificial limit set by the tool itself, but because processing happens in your browser's memory, very large files (typically several hundred megabytes) or dozens of high-resolution pages may slow down or strain lower-powered devices.
Does the PDF to Text tool work on scanned PDFs?+
It extracts the actual text layer embedded in a PDF. If a PDF is a scanned image with no underlying text layer, extraction will return little or nothing, since that would require optical character recognition rather than text extraction.
How does the PDF compressor reduce file size?+
Each page is re-rendered as an image at a reduced resolution and JPEG quality based on your chosen compression level, then reassembled into a new PDF. This trades a small amount of visual sharpness for a smaller file, and works best on image-heavy PDFs.
Can I edit the extracted text before downloading it?+
Yes. Extracted text appears in an editable preview box, so you can correct, trim, or rewrite it before downloading it as a .txt or .docx file.
All processing happens locally in your browser. No files are stored or transmitted.
