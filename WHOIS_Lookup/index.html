Free WHOIS and RDAP Domain Lookup

The Utiliverse WHOIS Lookup retrieves public domain-registration information using RDAP, or Registration Data Access Protocol. RDAP is the modern standardized replacement for older text-based WHOIS and can return structured data such as registrar, registration and expiration events, nameservers, domain status codes, DNSSEC information, registry identifiers, and public entity information.

Not every registry returns the same fields. Privacy rules, privacy-protection services, and registry policy can limit public contact details, so a missing registrant name does not necessarily mean the record is incomplete.

How to Use the WHOIS Lookup

Enter a domain or URL

Type a domain such as example.com or paste a full URL. Utiliverse removes the scheme, path, query string, port, and leading www prefix before performing the lookup.

Run the RDAP lookup

The browser sends the domain to the public RDAP bootstrap service at rdap.org, which routes the request to the appropriate registry RDAP service. No API key is embedded in the page.

Check the registrar

The registrar field identifies the organization responsible for managing the registration when that information is returned. An IANA registrar identifier is displayed when available.

Review important dates

Registration, expiration, and last-updated events are converted into readable dates. Utiliverse also estimates domain age and the amount of time remaining until the reported expiration date.

Inspect domain status codes

EPP status codes describe registration controls and pending operations. Transfer-prohibited or update-prohibited statuses are often security locks, while other statuses may describe deletion, renewal, or registry actions.

Check nameserver delegation

The nameserver list shows DNS servers delegated for the domain by the registry. This is useful when checking a DNS-provider migration or registrar configuration.

Check DNSSEC

When secure-DNS information is returned, the tool reports whether the registry delegation is signed. This is a registry-level indicator and not a complete end-to-end DNSSEC validation test.

View raw RDAP JSON

Use Raw RDAP to inspect the complete structured response, including registry-specific fields, notices, links, entities, and remarks that may not appear in the summary cards.

Practical Uses

Domain renewal checks

Use the reported expiration date as a quick reference when reviewing renewal schedules, while confirming final renewal status in the registrar account.

Registrar identification

Find the registrar managing a domain when ownership records are old, several registrars are used, or a website was inherited from another administrator.

DNS troubleshooting

Compare the registry nameserver delegation with the DNS provider you expect to use. This complements, rather than replaces, a full DNS-record lookup.

Transfer troubleshooting

Review EPP status codes when a domain transfer or update is being blocked. Transfer locks are common security controls and may need to be changed at the registrar.

Domain research

Registration date and age can provide context during technical or vendor research, but age alone does not prove legitimacy, trustworthiness, or continuous ownership.

WHOIS Lookup FAQ

What is WHOIS?

WHOIS is the traditional protocol and common term for querying registration information about domains, IP addresses, and autonomous systems.

What is RDAP?

RDAP stands for Registration Data Access Protocol. It provides registration information over HTTPS in structured JSON and is the modern successor to traditional WHOIS.

Why is the registrant name hidden?

Many registries and registrars redact personal information because of privacy law and privacy-protection services.

Can I check when a domain expires?

Yes, when the registry returns an expiration event.

Can I see the registrar?

Usually. Availability varies by registry and domain type.

Does this show DNS records?

It typically shows delegated nameservers and sometimes DNSSEC information, but it is not a complete A, AAAA, MX, TXT, or CNAME lookup.

Why can a lookup fail?

The domain may not exist, the registry may be unavailable or rate-limiting requests, or the top-level domain may not expose compatible public RDAP data.

Does Utiliverse save my lookup history?

This standalone page does not save a local lookup history. The requested domain is sent to the public RDAP service to obtain live registration data.
