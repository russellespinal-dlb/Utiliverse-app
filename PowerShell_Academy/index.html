HOW TO USE THE ACADEMY

Learn the concept. Check the reference. Practice safely.

1. Learn the object pipeline

Start with core commands, objects, filtering, and functions. The shortest exercises build confidence before you work with complex administration tasks.

2. Verify with Microsoft Learn

Use curated reference links to confirm command syntax, module-specific parameters, supported versions, and authentication requirements before running commands elsewhere.

3. Practice with limits you can trust

The practice lab evaluates only supported read-only exercise shapes against fictional data. Script Clinic highlights selected patterns without pretending to execute or fully parse your code.

Frequently asked questions

Does this site run PowerShell commands?

No. It recognizes a limited set of practice exercise patterns and displays simulated results. Real PowerShell execution requires installing PowerShell on your own trusted machine or using a properly managed environment.

Can I connect to my Microsoft 365 tenant?

No. The site has no Microsoft sign-in, backend, or Graph API access. Exchange, Teams, and Graph labs use fictional records, and generated commands are examples to verify before real use.

Can Script Clinic confirm that my script is safe?

No. It provides limited, educational pattern-based warnings and cannot guarantee correctness or safety. Use Microsoft PSScriptAnalyzer, manual review, least-privilege access, and an isolated test environment for real scripts.
